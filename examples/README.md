# Shopify Scraper API – code examples

Examples for every Shopify endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/apps.sh`](curl/apps.sh) | `bash apps.sh` |
| cURL (Bash) | [`curl/product.sh`](curl/product.sh) | `bash product.sh` |
| PHP | [`php/apps.php`](php/apps.php) | `php apps.php` |
| PHP | [`php/product.php`](php/product.php) | `php product.php` |
| C# | [`csharp/Apps.cs`](csharp/Apps.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Product.cs`](csharp/Product.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/apps.go`](go/apps.go) | `go run apps.go` |
| Go | [`go/product.go`](go/product.go) | `go run product.go` |
| Java | [`java/AppsExample.java`](java/AppsExample.java) | `java AppsExample.java` |
| Java | [`java/ProductExample.java`](java/ProductExample.java) | `java ProductExample.java` |
| Ruby | [`ruby/apps.rb`](ruby/apps.rb) | `ruby apps.rb` |
| Ruby | [`ruby/product.rb`](ruby/product.rb) | `ruby product.rb` |
| Node.js | [`nodejs/apps.mjs`](nodejs/apps.mjs) | `node apps.mjs` |
| Node.js | [`nodejs/product.mjs`](nodejs/product.mjs) | `node product.mjs` |
